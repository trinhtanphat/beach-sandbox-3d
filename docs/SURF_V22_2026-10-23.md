# Beach Sandbox v22 — natural long swell and smooth unified sea state
Date: 2026-10-23

## Objective
User requested the entire sea to feel more logical, believable and smooth. v21 fixed boat/visible-wave alignment, but the offshore water still had only small ripples and breaking crests; changing wave or whitewater sliders instantly changed shader geometry, foam spray, audio and boats, producing visual pops.

## What changed
- Added two broad, directional traveling swells in `oceanVertexShader`: `sin(uv.x*9 - t*1.08 + uv.y*3.4)*.018` and `sin(uv.x*14.5 + t*.72 - uv.y*5.7)*.011`. These gently roll offshore water below the smaller wind ripples and shoreward breaker crests, without introducing new textures or draw calls.
- Ocean fragment color uses a varying `vLongSwell` from the actual vertex displacement; highlights travel with 3D water geometry rather than unrelated static sine bands.
- `src/ocean-surface.js` now samples the same two extra 3D swell components for boat flotation, preserving CPU–GPU wave-height correspondence.
- Added `src/sea-dynamics.js` to interpolate target wave height and whitewater foam with frame-rate-independent exponential smoothing (0.45s and 0.35s response constants). This controller feeds the **same effective `sea.wave` and `sea.foam`** to ocean shader uniforms, GPU spray, 3D curling breaker lip, boat surface position and sea audio. Abrupt UI slider changes no longer pop all parts of the sea separately.
- Paused simulations freeze both the time clock and conditions. Restoring/importing island data immediately resets the controller to saved sea state. Saved JSON schema, coastline, life, birds and terrain remain unchanged.

## Remaining limitations and rollback
- Still artistic procedural surface deformation and shading, not physically simulated current, wind, tides, rigid-body hydrodynamics or CFD. Ocean vertex tessellation and normal interpolation create small differences compared with analytical continuous sampling.
- Preexisting nonblocking Three.js vendor chunk warning ~511 kB persists.
- User reference video is an aesthetic target, not a verified pixel-for-pixel match. A "100% match" is not established.
- Source branch: `feat/surf-v22-natural-swell-transitions`. Staging: https://shoreline-sandbox-3d-stage.hikvision.workers.dev/ . Production target after merge: isolated `shoreline-sandbox-3d` Worker https://beach.qs3d.site/ only. No unrelated Worker or DNS changes.
- Rollback baseline main v21 commit `b07549c3ec75bd293a0143a765dc7454d8ae3e56`.
