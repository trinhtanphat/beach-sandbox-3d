# Surf v8 — scalloped two-train breakers (2026-10-22)

## Objective
User requested continued improvement beyond GPU optimization v7. The existing shoreline breaking wave looked like a mechanically regular, singular white stripe. V8 introduces a second, weaker physically raised crest without extra mesh draw calls, and improves natural longshore irregularity while keeping foam synchronized.

## Changes
- One GPU mesh now holds **two** continuous 200 × 9-segment crest strips: phase shifts 0 and 0.56; strength factors 1.00 and 0.68. Each is gently curled, follows curved coast coordinates, and grows/shrinks with Wave height.
- A wave-front warp combines three longshore sinusoids (magnitudes 0.016, 0.007, 0.004 UV). The warp is shared exactly by the ocean vertex GLSL, ocean fragment GLSL, 3D lip GLSL, spray GLSL and the deterministic JS reference model.
- The warp frequencies are multiples of 2π×0.23 Hz, so the *whole* geometry/foam field repeats smoothly after one ~4.35-second cycle. The initial implementation broke periodicity; tests caught it before deployment and the implementation was corrected.
- All 460 foam points now carry a static per-particle phase-shift attribute, distributed across the main and secondary breaks, with secondary strength 0.68. No animated CPU geometry upload.
- 3D foam alpha gets gently varying break-section gaps using smooth noise, avoiding an opaque uninterrupted ribbon while preserving a visible breaker lip.
- Existing birds, reefs, native audio, terrain editor, Save/Load, sunset sliders and mobile tool controls are preserved.
