# Surf v14 — rising 3D shore swash and first real-hardware GPU baseline
Date: 2026-10-22

## Changes
- Added `swashCrestHeight(time,alongShore,uvX,wave)` as a deterministic reference for a new raised wavefront on beach sand.
- Swash GLSL vertex shader computes the existing run-up phase/front, then raises a narrow wave ridge by up to `0.05 * waveHeight` world units, decaying fully at the beginning of water retreat and the end of the cycle.
- Swash fragment shader fades bright, leading whitewater in sync with the 3D ridge. Lower-energy residual backwash filaments and dark exposed wet sand remain on the beach during water withdrawal.
- Entire effect stays in the existing 220 x 32 swash mesh, without extra draw calls, image downloads or per-frame JavaScript vertex uploads.
- Added tests for physically raised leading ridge, disappearance on retreat, cycle periodicity and GPU/CPU shader alignment.
- Added `scripts/create-deploy-delta.mjs` to extract compact, hashed app and HTML assets from the verified Worker bundle for isolated staging/production updates without resending unchanged Three.js/CSS assets.

## Real-GPU test — important
Windows local device `DESKTOP-PHA1S90`, interactive Session 2, Microsoft Edge on **Intel UHD Graphics 620, WebGL 2.0 via ANGLE Direct3D 11**, 1280 x 720 viewport, separate temporary browser profile (not the user's logged-in profile):
- Baseline v13 production: **44 FPS** displayed after about 7 seconds.
- New v14 staging: **47 FPS** displayed after about 7 seconds.
- Both HTTP 200, WebGL initialized, no page JavaScript errors.
- **These are single measurements**, not average FPS, 1% lows, hardware timer queries or rigorous A/B benchmarks. Do not infer a meaningful percent performance gain from them; they only establish that the 3D ridge runs on actual GPU hardware without obvious severe degradation.
- The one-time Windows Task Scheduler test job was deleted after completion to avoid unattended Edge launches.
