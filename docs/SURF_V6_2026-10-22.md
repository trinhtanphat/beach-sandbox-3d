# Shoreline Surf v6 — acceptance report (2026-10-22)

## Scope
- Repository: `trinhtanphat/beach-sandbox-3d`.
- Baseline: main merge `95ad82b5d84b2864c27543bebb6f4c5b30de0d0a`.
- Test site: https://shoreline-sandbox-3d-stage.hikvision.workers.dev/
- Public target: https://beach.qs3d.site/
- Only the isolated Shoreline Worker is to be updated; unrelated farm/game Workers, DNS, and secrets are untouched.

## Improvements
1. Ocean vertex swell, ocean foam sheet and 3D raised breaker lip share an explicit lifecycle: crest birth offshore, break, decay and disappearance at the shoreline.
2. Continuity envelope peaks mid-cycle and falls to zero at each periodic seam, removing the visible instant jump of white foam.
3. Foam particle alpha is now a per-sprite lifecycle parameter in a batched shader; 460 particles continue to use one draw call.
4. Smoothed procedural texture noise on the 3D lip replaces jagged cell-based opaque specks.
5. Narrow shoreline trailing foam is anchored to the moving swash front rather than painted on a fixed UV contour.
6. Adaptive renderer DPR decreases after at least 4 seconds of sustained FPS under 23 and increases gradually after sustained FPS above 53, capped by the device's prior display resolution. This preserves detail on fast devices and assists slow ones.

## Acceptance evidence
- Automated `npm run check`: 34/34 tests PASS and Vite build PASS.
- `npm run build`: outputs a standalone JS bundle with a non-fatal >500 kB size warning.
- Staging Workers deployment returned API HTTP 200.
- Cloudflare Browser Rendering desktop screenshot rendered the scene without the WebGL error panel.
- Local desktop has Intel UHD Graphics 620 (driver detected), but Playwright launching headless Edge exited with code 1002 in the remote service context. The headless benchmark did **not** run and no local hardware FPS result is claimed.
- Cloudflare's headless software-browser renderer reported about 2 FPS, **not** representative of a real interactive GPU browser.

## Known gaps
- The ocean is procedurally animated WebGL, not a physics / Navier-Stokes solver.
- Shoreline still uses precomputed coast shape; user terrain edits don't recalculate bathymetry for GPU breakers.
- A hardware accelerated browser in a user desktop session is still needed for FPS and smooth-motion validation; compare to the supplied Facebook reel by eye.
