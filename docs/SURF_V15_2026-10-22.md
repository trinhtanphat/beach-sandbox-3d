# Beach Sandbox 3D — v15 swash-front alignment audit
Date: 2026-10-22

## Goal
The v14 raised wet-beach swash ridge and the bright whitewater edge used different longshore displacement formulas. This could separate the visible white crest from actual 3D mesh elevation and create a visual discontinuity at the 4.35-second cycle seam.

## Fix
- Introduced one `swashNoiseGLSL` string exported from `src/waves.js`, containing a reusable procedural noise/warping helper and injected into both the **swash vertex and fragment shaders**.
- The vertex shader positions the 3D ridge using `swashFrontWarp(uv,uTime)`; the fragment shader places the bright foam front using the identical warp function. Removed a formerly independent `p.x` mesh offset that could detach the 3D ridge from whitewater.
- Made the warp periodic using sin/cos harmonic time modulation at `2π × 0.23` radians per second, so the warp repeats after the same complete wave period as the geometry.
- Added CPU equivalents (`swashHash`, `swashNoise`, `swashFrontWarp`) and tests covering finite/bounded front displacement, shared GPU function, removal of inconsistent mesh drift and full-cycle continuity.
- No change to existing island saves, terrain editing, audio, birds, Cloudflare DNS or other Workers. No new textures/draw calls.
