# Shoreline v10 — wet-sand swash, foam fidelity and Worker delivery QA
Date: 2026-10-22

## Scope and goal
Improve the visible water retreat on sand without adding a costly postprocessing stack, preserve the v9 two-layer GPU surf and foam slider, and make Worker delivery behavior reproducible. Baseline: GitHub main merge 2416680.

## Implementation
1. Match the CPU swash phase to GLSL: time*0.23 + 0.23 + sin(alongShore*9+0.3)*0.027 + alongShore*0.012. The old CPU helper used a simpler alongshore phase and was not an exact correspondence.
2. In the beach swash shader, treat wet sand as a separate darker, low-opacity trailing water film. Whitewater intensity changes only the foamy layer. Wet film does not disappear when the user reduces the Whitewater foam slider.
3. Add subtle trailing, broken whitewash streaks so beach recession is not just one regular solid white line. Retain the swash width/terrain profile, two raised breaker trains, 460 GPU sprites, sound, trees, saves and controls.
4. The Cloudflare Worker packager includes a content SHA-256-derived ETag per asset and separate cache policies: one-year immutable for hashed Vite /assets/, and no-cache/must-revalidate for HTML.
5. The repository's `npm run check` now runs Node tests, Vite build, packaging and an actual Node Web-API smoke test for every generated Worker asset, including exact decompressed byte equality with dist/, HEAD, conditional ETag 304, and 404/405.
