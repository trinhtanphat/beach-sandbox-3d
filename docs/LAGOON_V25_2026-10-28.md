# Lagoon v25 — carved inlet and sheltered physics

- Procedural elliptical excavation with sloped banks, a narrow channel connecting the ocean, submerged sandy floor and a sheltered boat.
- Bathymetry-clipped transparent water mesh blends into the existing open-ocean surface and updates after sculpt release, Undo, Reset, Load and Import.
- Slow ripples, depth-based water color, shoreline wash; shared Wave/Pause/Sun uniforms with the ocean.
- Forest avoids initial submerged terrain. Interactive tool placement rejects submerged trees; boats need enough water depth and remain moored in the lagoon.
- Existing browser-local JSON saves remain compatible and authoritative. Old saves may restore their old landscape without the new default lagoon.
- This is a bounded visual coastal model, not a mass-conserving CFD or sediment transport solver. Interactive terrain refreshes on sculpt commit, not every pointer movement.
- Verify npm run check locally; never publish over production before tests.
