# Shoreline surf v9 — foam density and independently cacheable 3D engine
Release candidate: 2026-10-22

## Goal
Improve the visible breakup of the two curling foam lines and let users tune whitewater separately from wave height, while preserving island saves. Reduce the cost of redeploying application changes by caching Three.js separately.

## Changes
- Ocean surface/fragment whitewater uses low-frequency, animated longshore variation to create more irregular broken crests, avoiding a mechanically continuous opaque line.
- An accessible Ocean Conditions control, "Whitewater foam" (30–180%, default 100%), adjusts ocean whitecaps, beach run-up swash, the raised 3D breaker lips and all 460 foam droplets via a shared uFoam uniform.
- The foam value is persisted in existing Save/Load and portable JSON (save schema remains version 1); old JSON files default to 100% without migration.
- Vite now emits a separately cacheable Three.js vendor file plus a smaller island application bundle. The >500 KB vendor warning remains (Three.js 510.98 kB minified), not hidden.

## Acceptance evidence
- 41/41 Node tests PASS and Vite build PASS. Added two tests for backward-compatible snapshots, foam clamping, and shader uniform propagation to crest/spray.
- Cloudflare staging Worker deployment HTTP 200: https://shoreline-sandbox-3d-stage.hikvision.workers.dev/
- Chromium browser-rendering scripted desktop QA PASS: foam 100% -> 160%, Save -> Load round trip retained foam=1.6 and 19,729 terrain points; WebGL did not fail; 14 birds present.
- Browser Rendering screenshot confirms interface and coast. Mobile QA 390×720 PASS: Tools opens, foam slider changes 100% -> 40%, no WebGL fallback.
- Build emits four assets (HTML, CSS, 41.35 KB app JS and 510.98 KB vendor JS); Worker packager includes all four.
- Browser Rendering is software-rendered. Physical Intel UHD Graphics 620 headless Edge previously failed (exit 1002), so there is still no reliable local hardware FPS benchmark.

## Release safety
Only isolated Cloudflare Worker shoreline-sandbox-3d may be updated after GitHub PR merge. Do not alter other Workers, Cloudflare DNS, local user browser profiles, or existing saved island data. Prior release commit 059ccba is the rollback reference.
