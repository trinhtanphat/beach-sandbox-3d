# Surf v24 — seaward return lanes and moored boat response
Date: 2026-10-23

## Why
The previous v23 update included a gentle longshore current in the whitewater and spray, but not the weak, channelized current returning offshore between incoming breakers. Boats still had wave-synchronized vertical motion without any surface-current drift.

## Implementation
- Extended `src/coastal-flow.js` with two bounded, smooth seaward outflow lanes centered near normalized alongshore positions 0.34 and 0.68. The return flow is strongest in the nearshore water zone and fades smoothly in deep water and at both board edges. Both CPU and three GPU shaders use the same `ripOutflowSpeed` and `foamReturnTravel` formulas.
- Foam flecks now gain a short offshore x offset according to their wave age (plus the existing longshore z offset). Ocean shader and breaker lip advect foam textures along the same returning flow, without moving wavefront meshes or increasing draw calls.
- Introduced `src/boat-current.js`: a small deterministic, time-driven positional response for boats near their original spawn/placement anchors. The x/z position follows the shallow-water longshore and return-flow fields, is bounded offshore and within the board, and never incrementally accumulates motion between frames. The same dynamically computed location is used for buoyancy and pitch/roll.
- `createBoat` preserves `anchorX/anchorZ`; Save/Export serializes the **stationary anchors**, not the animated current positions. Existing v1 snapshots still load through the same createBoat path, without a migration. Pause freezes the simulation clock and boat drift.
- No extra draw calls, external image fetches, required accounts, DNS changes, or new persistent fields.

## Limits and rollout
- Return channels and moored drift are simplified stylized kinematics rather than mass-conserving Navier–Stokes flow, tide dynamics, or a rigid-body hydrodynamic boat solver. The visible result is not a verified pixel-identical reproduction of the user's reference video.
- Existing nonblocking Three.js vendor bundle warning (~511KB minified) remains.
