# Surf v5 — geometry-backed breaking wave (2026-10-22)

## User-requested correction
The v4 water/foam still appeared like a moving white stripe in the water. The goal for v5 was a **physically raised, shore-hugging breaking lip**, coherent with wave displacement, with soft droplets and visible beach-edge wash.

## Implementation
- Added `src/breaker-lip.js`: 200 shore segments × 9 across-crest segments, tessellated 3D geometry updated with the surf phase. Uses just one transparent draw call, and interpolates an aquamarine-to-white raised curled crest.
- Crest x-position follows the actual curved coast: `shoreline(z) - 0.1 + (rightEdge - coast) * breakerPosition(...)`. The y-coordinate rises above sea level and grows with the user wave height slider.
- Aligned `breakerPosition()`'s alongshore drift with GLSL so CPU mesh and fragment/vertex foam stay centered on the same wave train.
- Modified the white beach-edge lingering foam to a narrower but brighter white lace; a thin wet film remains on sand during recession.
- Replaced square GL point sprites with a generated 32×32 radial-alpha texture. Still 460 sprites in one batch, no image fetch or copyrighted assets.
- Preserved old island saves, original environment/animals, undo/terrain tools and existing URLs.
