# Surf v18 — organic GPU foam-spray silhouettes
Date: 2026-10-23

## Intent
Improve visible variety in beach-breaking spray. Prior releases drew 460 identically shaped, soft circular white sprites along both wave trains. At a distance this was overly regular even after improving the 3D crest, wavefront breakup and foamy shoreline.

## Implementation
- `src/foam-atlas.js` creates a 64 × 64 RGBA8 deterministic texture comprising four 32 × 32 irregular foamy bubble clusters, each with overlapping lobes, micro-breakup and transparent gutters. No external image/license requirement.
- `src/surf-spray.js` attaches a static `aFoamVariant` GPU buffer attribute, assigned 0–3 across all 460 existing particles. The fragment shader selects a tile from the same atlas using `gl_PointCoord` and the variant. Existing wave height, foam intensity, train phase, coastal anchors and simulation clock remain unchanged.
- **No additional draw calls**: all 460 particles remain in the same THREE.Points draw. No per-frame BufferAttribute updates.
- A 64×64 RGBA8 atlas uses ~16 KiB uncompressed GPU pixel data versus the prior 32×32 (~4 KiB). It is small, embedded in the existing JS bundle and uploaded once at initialization.
