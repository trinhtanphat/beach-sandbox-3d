# Surf v21 — physically coherent boat flotation
Date: 2026-10-23

## Observed inconsistency
After v20 unified the tropical island biomes, boats still bobbed using an isolated low-amplitude sine function and rotated about one axis independently of the two GPU swell trains. This led to ships seemingly rising when the visible water surface was falling.

## Implementation
- Add pure deterministic `src/ocean-surface.js` with `oceanHeight(time,x,z,wave)` implementing the same virtual water height at any offshore world coordinate as `oceanVertexShader`: normalized coastal UV, two phase-shifted curling breaker crests, fade envelope, two background swells and shoaling amplification.
- `boatPose` samples the water surface and local gradients (five height samples) relative to each hull's world heading. Pitch/roll are capped at +/-0.14 radians to avoid implausible capsizing in the stylized seas. The hull is partially submerged instead of floating at a fixed Y location.
- The existing animated boat loop uses `boatPose` and the ocean's `elapsed` clock / `waveHeight` slider; pause freezes the clock and boat position simultaneously.
- Existing save JSON schema, starting boat positions, placed items, bird flock, sound, editable terrain and Cloudflare DNS are unchanged.

## Limitations
- The boat rides an analytical approximation of the tessellated water surface (not a rigid-body buoyancy solver; no current, wind or collision dynamics). The GPU rasterizer interpolates between vertices, so subvertex water heights can differ slightly.
- Three.js vendor chunk still ~511 kB minified and triggers a nonblocking Vite warning.
- A true 100% match to the reference video has not been demonstrated.
