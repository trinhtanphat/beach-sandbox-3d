# Beach Sandbox 3D — v11 staggered breaker acceptance
Date: 2026-10-22

## Objective
The previous coastline surf still broke as an almost continuous white ribbon. User requested further improvements to breaking waves and sea foam. V11 makes the crest emerge in staggered patches along the curved coast, keeping the actual water whitewater, raised foam lip and foam particles synchronized.

## Changes
- Add a deterministic periodic `sectionBreak(time, alongShore, trainShift)` function with a corresponding reusable GLSL `breakingSections()` definition. Signal varies by two coastwise frequencies and wave-cycle harmonics, bounded to [0.16,1.0] and repeatable after 1/0.23 seconds.
- Ocean fragment shader multiplies the primary / secondary wave foam separately by this shared section-breaking signal, respecting shifts 0 and 0.56.
- Breaker-lip vertex shader forwards the wave-train phase offset to its fragment shader; crest opacity uses the same break-section value while keeping geometry animated entirely on GPU.
- Spray's GPU vertex shader gates per-sprite foam opacity with the same longshore section signal and wave train. CPU reference functions expose matching section/visibleLife for deterministic tests.
- No modifications to saved-island format, terrain sculpt tools, browser storage, ambient sound or third-party Workers.
