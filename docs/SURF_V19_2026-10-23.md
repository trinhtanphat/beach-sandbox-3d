# Shoreline v19 — branching backwash foam rivulets
Date: 2026-10-23

## Motivation
The beach had a physically exposed wet-sand footprint after each wave (v13) but largely uniform thin backwash lines; the retreat looked too much like a flat animated stripe. Introduce fine, branching, white foam rivulets that follow exposed sand and disappear before the next wave arrives.

## Implementation
- New deterministic CPU reference `backwashRivulet(time, alongShore, across, strength)` in src/waves.js.
- Fragment shader adds thin, displaced streams using alongshore frequency, shoreward coordinate and harmonic time. Mask them by `exposed * withdrawing`, so whitewash only appears in newly exposed sand behind the retreating waterline.
- The expression uses an **integer harmonic** of the 0.23 Hz swell-cycle phase, fixing an early v19 regression detected by the new tests: the first version used non-integer `turn*1.4`, which would jump when the wave cycle wrapped.
- No extra geometry, draw calls, image downloads, new uniforms or saved-state schema changes. Existing uFoam slider controls the rivulets with the other foam layers.
